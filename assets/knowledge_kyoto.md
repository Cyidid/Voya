# 京都旅行知识库

## 景点推荐

### 世界遗产寺社（京都有17处世界遗产）
- **伏见稲荷大社** — 数千座朱红色鸟居绵延山间，全球最受欢迎的日本景点之一。免费参观，建议清晨6:00前到达避开人潮，全程爬山约2-3小时（至一之峰顶），可只走30分钟至千本鸟居最精华段。
- **金閣寺（Kinkaku-ji）** — 被金箔包覆的舍利殿倒映镜湖，门票¥500，建议上午9:00开门时入场（人最少）。
- **岚山 / 竹林小径** — 嵐山竹林最佳游览时间为清晨7:00-8:00（人少且光线柔和），附近天龙寺（世界遗产，入庭园¥500）与保津川游船（¥4,100）可组合。
- **清水寺** — 悬崖上的木质舞台，可俯瞰京都市区。门票¥400，夜间特别开放期（3月、8月、11月末）灯光极美，需提前查询日程。
- **二条城（Nijo-jo）** — 德川幕府京都行宫，鸟居式走廊，脚踩会发"吱呀"声（莺声地板）。门票¥1,300，含御殿参观。

### 传统街区
- **祇园（Gion）** — 京都最著名的花街，舞妓与艺妓文化的中心。白川南通与花见小路是最佳散步路线，傍晚6-8pm有机会偶遇出行的舞妓，但请勿追拍或阻拦。
- **哲学之道（Philosopher's Path）** — 全长约2km的疏水渠小径，3月末樱花盛开时如粉色隧道，11月红叶映水。沿途有南禅寺（三门⛩¥600）、永观堂（¥600）。

### 庭园文化
- **龙安寺枯山水石庭** — 15块石头的世界遗产枯山水庭园，引发无数哲学思考。门票¥600。
- **修学院离宫 / 桂离宫** — 日本皇室庭园，需提前在宫内厅网站申请预约（免费），参观须有日语或英语导游随行。

## 美食推荐

### 京都特色料理
- **京料理（Kaiseki懐石）** — 日本最精致的多道课程料理，使用时令食材，注重器皿与季节美学。高端预算推荐：祇园 さゝ木、菊乃井（¥15,000-30,000/人）；中档：京都车站附近的懐石套餐（¥5,000-8,000/人）。
- **湯豆腐（Yudofu）** — 嵐山与南禅寺一带的名物，清淡豆腐涮锅，配以精致小菜，人均约¥3,000-5,000。推荐：南禅寺附近奥丹（400年老店，¥3,960定食）。
- **京漬物（腌菜）** — 西京漬（白味噌腌渍）、千枚漬（圆白萝卜）为必买伴手礼。锦市场（"京都的厨房"）有现场试食。
- **抹茶甜品** — 京都是日本抹茶之都。推荐：中村藤吉本店（伏见稻荷/宇治），抹茶芭菲、抹茶蕨餅；辻利兵衛本店（宇治）。

### 平价美食
- **锦市场（Nishiki Market）** — 400年历史的室内街市，试食免费且量足，章鱼蛋、玉子烧等街头食物各约¥300-500。
- **出町柳的出町ふたば** — 名代豆餅（红豆麻糬），每日早排长龙，一个¥210，限量购买。

## 交通信息

### 市内交通
京都市内公交系统（市巴士）是最重要的交通工具，覆盖大多数景点：
- **主要线路**：101/102号绕行金阁寺、银阁寺、哲学之道；206号连通清水寺、祇园、金阁寺
- **市巴士一日券**：¥700，可无限次乘坐市巴士，极超值（单次¥230）
- **嵐電（岚山电车）**：连接四条大宫与嵐山，¥250/次，复古电车本身是一景
- **叡山电车**：连接出町柳与鞍马/贵船
- **地铁**：乌丸线（南北）与东西线（东西），主要用于车站与市中心通达

**注意**：旺季（3月末、11月）公交极度拥挤，建议使用自行车（全市自行车租赁¥1,000-1,500/天）。

### 对外交通
- **京都站（Kyoto Station）** — 新干线（东海道山阳线）直达东京约2.5小时（¥13,320）、大阪约15分钟（¥1,420）、广岛约1.5小时
- **JR Pass 覆盖范围** — 持JR Pass可免费乘坐新干线（指定席需预约）及嵐山JR线

## 住宿建议

### 高端（¥30,000+/晚）
- **俵屋旅館（Tawaraya）** — 日本最著名町家式旅馆，300年历史，含全程会席料理，需提前数月预约
- **祇园一带の小型精品旅馆** — 近花街，体验最纯正的京都情调

### 中档（¥10,000-25,000/晚）
- **河原町/木屋町区域** — 交通便利，步行可达祇园，餐饮丰富
- **烏丸/四条周边** — 地铁直达，购物便利，价格相对合理

### 经济型（¥5,000-10,000/晚）
- **京都站附近** — 交通最方便，巴士与新干线均可直达，价格是市内最低
- **町家民宿（Machiya Guesthouse）** — 改造自京都传统连排住宅，性价比高，体验独特

## 实用信息

### 气候
- **春季（3月末-4月初）** — 赏樱旺峰，全城人满为患，酒店需提前3-6个月预订
- **夏季（7-8月）** — 高温多湿，35°C以上；祇园祭（7月整月）是京都最重要的节庆
- **秋季（11月）** — 红叶季，全城最美的时节，人流量仅次于樱花季
- **冬季（12-2月）** — 淡季，人少价低，金阁寺与竹林偶有积雪，极为梦幻

### 必备贴士
- 清晨是游览热门景点的黄金时段（7:00-9:00），许多景点开门前30分钟人最少
- 祇园花街（花見小路）禁止在私人胡同拍摄，违规将受处罚，请尊重当地规定
- 哲学之道、南禅寺一带骑自行车游览最为舒适，多数民宿提供自行车出租或推荐附近租赁点
- 寺庙参观注重安静，请勿大声喧哗，进入建筑物内须脱鞋

### 语言与支付
- 日元（JPY），1 JPY ≈ 0.049 CNY
- 小型商铺与寺庙入口多为现金，建议携带¥20,000-30,000现金
- 英语在热门景点基本通行，偏远寺社可能无英语服务
