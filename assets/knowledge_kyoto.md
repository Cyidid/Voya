# 京都旅行知识库

## 景点推荐

### 世界遗产寺社（京都有17处世界遗产）
- **伏见稻荷大社（Fushimi Inari）** — 数千座朱红色鸟居绵延稻荷山间，全球最受欢迎的日本景点之一，免费参观。建议清晨6:00前到达（鸟居内几乎无人），或夜晚21:00后（全年不关门），至千本鸟居最精华段约30分钟，至一之峰顶全程约2-3小时。乘JR奈良线至「稲荷」站即达（京都站出发约5分钟）。
- **金閣寺（Kinkaku-ji/金阁寺）** — 金箔包覆的舍利殿倒映镜湖，门票¥500，开放8:30-17:00。建议9:00开门时入场，旅游团9:30-11:00大量涌入，下午15:00后人流稍减。
- **岚山 / 竹林小径（Arashiyama Bamboo Grove）** — 竹林最佳游览时间为清晨7:00-8:00，光线柔和、人极少；游船（保津川游船，¥4,100，约2小时）与嵐山竹林组合极佳。附近天龙寺（世界遗产，庭园¥500）与渡月桥（免费，四季皆美）可同日游览。
- **清水寺（Kiyomizudera）** — 悬崖上的木质舞台俯瞰京都市区，门票¥500（近年调价至¥600），开放6:00-18:30，夜间特别开放（3月、8月、11月末，约¥400加收）灯光极美需提前查日程。清晨6:00-7:30游客极少，是拍摄最佳时机。
- **二条城（Nijo-jo）** — 德川家康京都行宫，莺声地板（走路会发"吱呀"警报声）极具历史感。门票¥1,300，含御殿参观，花见小路的四季庭园配置精妙。
- **龙安寺（Ryoan-ji）** — 枯山水石庭（15块石头，无论从哪个角度都看不全，禅意深远）是世界遗产。门票¥600，清晨8:00入场人最少。附近金閣寺可同日串联。

### 传统街区
- **祇园（Gion）** — 京都最著名的花街，舞妓与艺妓文化的中心。白川南通与花見小路是最佳散步路线，傍晚17:00-19:00有机会偶遇出行的舞妓（切勿追拍或拦路）。石塀小路是最幽静的石板巷道，强烈推荐。
- **哲学之道（Philosopher's Path）** — 全长约2km的疏水渠旁步道，3月末樱花盛开时如粉色隧道，11月红叶映水极美。沿途南禅寺（三门¥600，水路閣免费）、永観堂（红叶期¥600）。
- **祇園四条至清水寺周边** — 二年坂、三年坂（宁宁之道）是京都保存最完好的石板老街，陶瓷、漆器、和纸工艺品店鳞次栉比，人均消费较高但体验最纯正。

### 庭园文化
- **修学院离宫 / 桂离宫** — 日本皇室庭园，须提前在宫内厅网站（sankan.kunaicho.go.jp）申请预约（免费），参观须由官方导游随行（日/英语），3个月前即开放申请。
- **苔寺（西芳寺）** — 120种苔藓覆盖整个庭园，世界遗产。完全预约制，须提前书信预约（现已开放网络申请），仅接受少量游客，参拜费约¥4,000，体验极为独特。

### 宇治（京都近郊，电车30分钟）
- 全球抹茶之都，有平等院（世界遗产，¥1,000，日元10円硬币上的建筑）、宇治上神社（日本最古老神社建筑）。沿宇治川散步约1.5小时，中村藤吉本店（抹茶芭菲）是必去打卡地。

## 美食推荐

### 京都特色料理
- **京料理（Kaiseki懐石）** — 日本最精致的多道课程料理，时令食材+器皿+季节美学的高度融合。高端推荐：祇園 さゝ木、菊乃井（均需提前数月预约，¥20,000-40,000/人）；中档体验：祇园白川一带午间懐石套餐（¥5,000-10,000/人），午间比晚间便宜40%。
- **湯豆腐（Yudofu）** — 嵐山与南禅寺一带名物，京都木棉豆腐在昆布高汤中涮煮，配精致小菜。推荐：南禅寺旁奥丹（400年老店，¥3,960定食），需提前预约。
- **京漬物（腌菜）** — 西京漬（白味噌腌鱼/肉）、千枚漬（圆蔓菁）、柴漬（紫苏腌茄子）为三大名漬物。锦市场有最多品种，可试食后购买。
- **抹茶甜品** — 京都是日本抹茶之都（宇治为产地）。中村藤吉本店（宇治）：抹茶芭菲¥1,760、抹茶蕨饼¥1,155；辻利兵衛本店（宇治）；一保堂茶铺（寺町二条）可试饮并购买茶叶。

### 平价美食
- **锦市场（Nishiki Market）** — 全长390m的室内街市，400年历史的"京都厨房"，试食免费，章鱼蛋（¥300）、玉子烧（¥300）、京漬物等街头食物，建议上午10:00-12:00游览，下午部分摊位关闭。
- **出町ふたば（Demachi Futaba）** — 出町柳商店街内，名代豆餅（红豆麻糬，¥210/个）是京都最知名的和菓子之一，每日早晨排队，售完为止，建议9:00前到。
- **第一旭拉面 / 新福菜館** — 京都站附近，京都风酱油拉面，早晨7:30开业即有排队，一碗约¥850-1,000，当地人的早餐首选。

## 交通信息

### 市内交通
- **市巴士（市バス）** — 京都最核心的交通工具，覆盖大多数景点，单次¥230，日券¥700（可无限次，极超值）。主要线路：101/102号串联金閣寺-銀閣寺-哲学之道；205/206号连通京都站-清水寺-祇园-金閣寺。
- **京都市地铁** — 乌丸线（南北）贯通京都站-四条-三条-北大路；东西线连通二条城-三条京阪。地铁1日券¥800，地铁+巴士联合1日券¥1,100（最划算）。
- **嵐電（岚山电车/京福电铁）** — 连接四条大宫与岚山，¥250/次，复古单节电车是一景，建议搭乘往返岚山。
- **叡山电车** — 出町柳至鞍马/贵船（红叶期极美），¥430-560，秋季需提前预约。
- **自行车** — 强烈推荐！京都市内地势平坦，道路规整，骑行是最自由的游览方式。租赁约¥1,000-1,500/天，各大民宿多可代订。

### 对外交通
- **京都站（JR Kyoto Station）** — 新干线（山阳东海道线）直达东京约2.5小时（¥13,320自由席）、大阪约15分钟（¥560）、广岛约1.5小时；JR Pass全额覆盖（包含新干线指定席，但需提前预约座位）。
- **京阪电铁** — 至大阪淀屋橋約45分鐘（¥430），沿线伏见稻荷、祇园四条均有站。

## 住宿建议

### 高端（¥40,000+/晚）
- **俵屋旅館（Tawaraya）** — 日本最著名的町家式旅馆，300年历史，1日2食全程会席料理，需提前3-6个月预订，坐拥禅意庭园
- **柊家旅馆** — 三条附近，同为百年老铺，历代天皇与外国元首曾入住
- **祇园 八坂の塔周边精品旅馆** — 直对五重塔，体验最纯正的京都情调

### 中档（¥15,000-35,000/晚）
- **河原町/木屋町区域** — 交通便利，步行可达祇园与清水寺，餐饮选择丰富
- **烏丸/四条周边** — 地铁直达，购物便利，商务旅客集中，价格稍低于河原町

### 经济型（¥5,000-12,000/晚）
- **京都站附近** — 交通最方便，巴士直达全市，是性价比最高区域
- **町家民宿（Machiya Guesthouse）** — 改造自京都传统连排住宅（京町家），竹帘、坪庭、走廊极具京都美学，价格¥8,000-20,000/晚，全程独栋租用最有情调

## 实用信息

### 气候
- **春季（3月末-4月初）** — 赏樱旺峰，全城人满为患，酒店须提前3-6个月预订；4月5日前后哲学之道与岚山满开最美
- **夏季（7-8月）** — 高温多湿，35°C以上，盆地地形导致体感极热；7月是祇园祭（整月活动），宵山（7月14-16日）是最热闹的夜市
- **秋季（11月）** — 红叶季，全城最美的时节，人流量仅次于樱花季；東福寺与永観堂是红叶圣地
- **冬季（12-2月）** — 淡季人少价低，金閣寺与竹林偶有积雪极为梦幻，泡汤（岚山温泉）是最佳体验

### 必备贴士
- 清晨（7:00-9:00）是游览热门景点的黄金时段，绝大多数景点免费或价格不变，旅游团9:30后才大量涌入
- 祇园花街（花見小路私人胡同）禁止拍摄，违规将受罚款，请尊重当地生活
- 哲学之道、南禅寺一带骑自行车游览最舒适，可按自己节奏自由停留
- 寺庙参观注重安静，进入建筑物内须脱鞋，请保持低声交流
- 旺季（3月末、11月）公交极度拥挤，建议提前1站上车，或步行20分钟替代一次单程

### 语言与支付
- 日元（JPY），1 JPY ≈ 0.049 CNY
- 小型商铺与寺庙入口多为现金，建议准备¥20,000-30,000现金
- 英语在热门景点基本通行，偏远寺社可能无英语服务；中文在主要旅游地有简单标识
