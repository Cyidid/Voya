# 广州旅行知识库

## 景点推荐

### 历史文化类
- **陈家祠（陈氏书院）** — 清代广东民间建筑艺术的巅峰之作，砖雕、木雕、石雕、陶塑、灰塑"五大工艺"集于一身，是岭南传统建筑的集大成者。门票¥50，建议游览2-3小时，每周一闭馆，地铁1号线陈家祠站A出口直达。
- **南越王博物院** — 西汉南越文王赵眜之墓（约公元前122年），出土丝缕玉衣、错金铭文虎节等国宝级文物。门票¥15，建议游览2小时，地铁8号线西门口站步行5分钟。
- **广州博物馆（镇海楼）** — 明代古城楼建于越秀山上，俯瞰城市，馆内陈列广州2000年历史。免费参观，须提前在微信小程序预约，每周一闭馆，地铁2号线越秀公园站步行10分钟。
- **沙面岛** — 19世纪英法租界遗留的欧式建筑群，完整保留了100余座新古典主义与巴洛克风格建筑，免费漫步。配合珠江边的白鹅潭夜景，傍晚游览最佳。毗邻上下九步行街。

### 现代地标
- **广州塔（小蛮腰）** — 高600m，全球最高电视塔之一。主观光层（422m）门票¥138，塔顶旋转餐厅（¥200+餐饮消费）需提前订座。建议傍晚18:30后入园，俯瞰珠江两岸夜景。最佳拍摄外景点：对岸海心桥（步行桥）或猎德大桥旁江边。
- **广州图书馆 / 广东省博物馆** — 位于珠江新城文化广场，广东省博物馆（免费，须预约）馆藏岭南文物与海上丝绸之路史料，新馆设计独特。附近广州大剧院（建筑出自扎哈·哈迪德）可从外拍照。
- **北京路步行街** — 广州最古老的商业街，地面保留汉唐至明清历代古道遗址（玻璃覆盖展示），距广州起义纪念馆步行5分钟，地铁1号线公园前站出口即达。

### 自然公园类
- **越秀公园** — 广州最大城市公园，内有五羊雕像（广州城市标志）、明代古城墙遗址、越秀山博物馆。免费开放，清晨有广场舞与太极，7:00前人极少，五羊雕像是标配打卡点。
- **白云山** — 广州城市"绿肺"，共9个景区。摩星岭（海拔382m）可俯瞰城市与珠三角平原；明珠楼片区有索道（¥35/单程）；云台花园（免费）是婚纱摄影热门地。入山门票¥5（部分区域另收费），建议工作日清晨进入，避开周末人潮。
- **珠江夜游** — 乘游船游览珠江两岸夜景，途经广州塔、猎德大桥、海心桥、白鹅潭。票价约¥100-150/人，推荐20:00出发班次（沿途灯光秀已全亮），建议提前在美团/携程购票。

### 美食街区类
- **上下九步行街** — 西关骑楼历史街区，汇聚广式烧腊、糖水铺、老字号糕点与新潮餐厅，夜市18:00后最热闹，地铁1号线长寿路站步行5分钟。
- **天河城 / 正佳广场 / 太古汇** — 天河区珠江新城核心商圈，国际奢侈品牌与本土品牌同场，美食广场选择极多，周末人流极大建议平日前往。

## 美食推荐

### 广式早茶（"饮茶"文化，必体验）
广式早茶是广州最具代表性的饮食文化体验，推荐在工作日9:00-11:00进行，避开周末排队。点心（点心师推车现场选取或手写点单），配普洱、菊花或铁观音。

- **莲香楼**（文昌南路）— 百年老字号，1889年创立，蛋挞（¥12）、马拉糕（¥18）、叉烧包（¥18）为招牌，工作日不排队，人均¥60-80
- **陶陶居**（第十甫路 / 太古汇）— 1880年开业，民国风装潢，虾饺晶莹剔透、干蒸烧卖弹嫩，周末需提前1小时排队，人均¥70-100
- **广州酒家**（文昌路本店）— 号称"食在广州第一家"，叉烧、脆皮乳猪与各类精品点心，人均早茶¥80-120，正餐¥150-250
- **泮溪酒家**（荔湾湖公园旁）— 园林式茶楼，环境最具岭南韵味，适合情侣或商务接待，人均¥80-120

### 街头小吃（性价比首选）
- **肠粉** — 推荐西关布拉肠粉（手拉式）和沙河粉，一份猪肉/海鲜肠粉¥8-15，口感嫩滑，酱汁是灵魂，用芝麻酱+花生油调制
- **云吞面（细蓉）** — 以猪肉+鲜虾配手工细面，汤底用猪骨+虾壳熬制，一碗小碗（细蓉）约¥15-25；推荐越秀区、荔湾区老店
- **烧腊（叉烧/烧鸭/烧鹅）** — 以深井烧鹅、化皮乳猪最负盛名；推荐伙牌烧腊（各区均有分店，单拼¥25-40/位）；太爷鸡（文昌鸡）是另一特色
- **双皮奶 / 姜撞奶** — 顺德（番禺）双皮奶为正宗起源；大良双皮奶（约¥18/碗）口味最纯正；城区多数糖水铺可点到
- **糖水** — 广州甜品文化的体现，芝麻糊（¥15）、核桃露、杨枝甘露（¥20-30）是常见款，专门糖水铺营业至凌晨

### 夜宵文化
- **宵夜文化** — 广州人称"宵夜"而非夜宵，22:00后才真正热闹，可持续至凌晨2:00
- **海鲜夜市（食街）** — 淘金路、白云大道沿线有多条海鲜排档街，生蚝（¥30-60/打）、砂锅粥（¥30-60/人）、白灼虾，人均¥80-150；建议结伴前往

## 交通信息

### 市内交通
- **广州地铁** — 共14条（含APM等）线路，运营至约23:00，覆盖全市主要景点、商圈与交通枢纽。推荐使用岭南通交通卡（押金¥30，余额可退）或微信/支付宝扫码乘车，单程¥2-10。
  - 1号线：西朗-广州东（覆盖陈家祠、长寿路、公园前、烈士陵园、天河体育中心）
  - 3号线：机场-广州南（覆盖天河城、珠江新城、广州塔）
  - APM线：珠江新城区域内摆渡，免费换乘（持有3号线票）
- **公共汽车** — 500余条线路，覆盖面最广，但高峰期较慢，推荐用于地铁未覆盖的区域
- **滴滴打车** — 市区起步价约¥13，机场/火车站至市区约¥60-150，是灵活出行的最佳选择

### 对外交通
- **广州白云国际机场（CAN）** — T1/T2双航站楼，地铁机场北/机场南站（3号线北延线）直达天河城约40分钟，票价约¥8；国际国内航班均十分密集。
- **广州南站** — 高铁枢纽，可达深圳北（约30分钟，¥75高铁）、香港西九龙（约1小时，¥213，须购高铁跨境票）、北京西（约8小时，¥1,100商务座）、上海虹桥（约5小时，¥780商务座）。地铁7号线/22号线连通市区（约40-60分钟）。
- **广州站（广州火车站）** — 普通列车，连接全国二三线城市，广州东站（地铁1号线）服务部分城际列车

## 住宿建议

### 高端（¥600+/晚）
- **广州W酒店（珠江新城）** — 顶层无边际泳池俯瞰珠江，设计感强，近地铁APM线猎德站，夜景出色
- **文华东方酒店（珠江新城）** — 全球最高规格服务，西餐与粤菜餐厅均属城中顶级水准
- **白天鹅宾馆（沙面岛）** — 地标级历史酒店，坐拥珠江，近陈家祠与上下九，本地老广的仪式感首选

### 中档（¥200-500/晚）
- **珠江新城板块** — 交通便利，近天河CBD、广州塔，餐饮选择最丰富，近地铁3号线/APM线
- **越秀/北京路板块** — 历史感强，步行可达多个历史景点，价格比珠江新城低20%

### 经济型（¥100-200/晚）
- 推荐地铁沿线汉庭、如家、全季等连锁品牌；距陈家祠站或北京路站步行5分钟内性价比最高。青旅集中在越秀区（人民公园周边）与海珠区（广州塔周边）

## 实用信息

### 气候
- **春季（3-5月）** — 温暖潮湿，常有阴雨与"回南天"（墙面返潮），携带折叠伞，体感较中国北方湿冷
- **夏季（6-9月）** — 高温多雨，最高气温可达37°C，注意防晒补水，午后雷阵雨频繁但通常短暂
- **秋季（10-11月）** — 广州最佳旅游季，晴朗干爽，气温22-28°C，适合所有户外活动
- **冬季（12-2月）** — 温凉干燥，气温8-15°C，偶有短暂寒流，轻外套即可，极少下雪

### 必备贴士
- "食在广州"是城市名片，早茶（饮茶）是灵魂体验，建议安排一次正式早茶（9:00-11:00），学会点心术语（一盅两件、叫点心等）
- 广州话（粤语）是当地第一语言，但普通话全面通行；英语在核心景区和高端商场基本可用；本地人交流亲切热情
- 上下九与北京路夜市人流密集，随身财物注意安全，避免携带大量现金
- 出行避开全国黄金周（春节/五一/十一），广州是旅游热门目的地，这些时段人极多
- 珠江夜游船票提前在美团/携程购买（约¥100-150/人），现场可能无票或溢价

### 签证与支付
- 中国大陆居民无需签证，持二代身份证即可；外籍游客按一般中国签证规定入境
- 微信支付/支付宝覆盖约98%的消费场景，现金需求极低；外籍游客可使用支付宝国际版（绑定境外信用卡）
