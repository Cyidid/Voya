# 云游 Voya · AI Travel Planner

> 通过"旅行行程规划"这一具体场景，实现并对比**三种主流 AI 设计范式**，同时开展负责任 AI 公平性分析。

---

## 三种 AI 范式一览

| 前端名称 | 范式 | 核心机制 | 响应时间 | 城市覆盖 | 可解释性 |
|---------|------|---------|---------|---------|---------|
| 经典规划 | 规则系统 | 人工编写专家规则库，确定性匹配 | < 0.1ms | 25 个固定城市 | ★★★★★ |
| 偏好匹配 | 监督学习 | VotingClassifier 集成分类，86.8% 准确率 | < 1ms | 全局（训练分布内） | ★★★★ |
| 实时规划 | 目标导向智能体 | LLM 自主决策 + 工具调用 + 实时联网 | 30–60s | 全球无限制 | ★★★ |

**输入**：城市、天数、预算、兴趣偏好、出行类型、人数、出发地、出发日期、特殊需求  
**输出**：逐日详细行程（Markdown）+ 预算参考 + 餐厅/交通/住宿建议 + 模拟票务预订

---

## 公平性分析核心结论

| 受保护属性 | AOD | 等级 |
|-----------|-----|------|
| 特殊需求（has_special） | +0.025 | ✅ 公平 |
| 出行群体（家庭 vs 非家庭） | +0.163 | ⚠️ 存在偏差 |

> 家庭群体被系统性预测为较低多样性的推荐类型。已通过等权采样和软规则标注进行缓解。  
> 详见 [SYSTEM_GUIDE.md § 9](SYSTEM_GUIDE.md)

---

## 技术栈

- **后端**：FastAPI + Python 3.12，SSE 流式输出
- **前端**：原生 HTML / CSS / JS，无框架，marked.js 渲染 Markdown
- **AI**：OpenAI 兼容 API（豆包 / 通义千问 / DeepSeek）
- **知识库**：ChromaDB 本地向量数据库（22 城市，294 条文档）
- **联网搜索**：Tavily API
