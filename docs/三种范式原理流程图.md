# 三种 AI 范式原理流程图 — 上海→东京 7天家庭游

> 统一演示输入：
> **"我想从上海出发去东京玩7天，和家人一起（带两个小孩），我们喜欢自然、动漫文化，预算较高，希望行程不要太赶。"**

## 三种范式对比总结（上海→东京 7天家庭游）

| 维度 | 规则系统 | 监督学习 | Agentic AI |
|------|---------|---------|-----------|
| **核心逻辑** | if-else 条件匹配 | 16维特征 → 三模型投票 → 8分类 | LLM 自主调用工具 → 自然语言生成 |
| **决策权** | 程序员（人工规则） | 模型（从数据中学习） | LLM Agent（自由裁量） |
| **"动漫"兴趣** | ✗ 丢失（无映射） | ✗ 丢失（不在兴趣词表中） | ✓ 完全理解，自动搜索 |
| **"两个小孩"人数** | ✗ 未匹配正则 | ✗ 默认2人 | ✓ 从自然语言理解 |
| **推荐类型** | 按兴趣轮换(自然/文化) | 亲子家庭游(35%) | 自由生成（家庭亲子动漫之旅） |
| **景点来源** | 固定规则库 | 模板+城市映射(5城) | 实时搜索(Tavily) |
| **迪士尼信息** | ✗ 不在景点池 | ✓ 模板中有 | ✓ 实时门票价格 |
| **灌篮高手镰仓** | ✗ 无 | ✗ 无 | ✓ 自动推荐 |
| **天气建议** | ✓ 查气候表 | ✗ 无 | ✓ 实时搜索 |
| **费用估算** | ¥75,200（公式） | ¥72,800（公式） | LLM估算 |
| **响应时间** | <0.1ms | <1ms | 30-60s |
| **可重复性** | 100% 一致 | 100% 一致 | 每次不同 |
| **可解释性** | 完全透明，规则可见 | 特征重要性可见 | 工具链步骤可见 |
